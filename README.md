# แดชบอร์ดติดตามแผนปฏิบัติการ กยท. ปีงบประมาณ 2569

เว็บแดชบอร์ดหน้าเดียว (static HTML) สำหรับติดตามผลการดำเนินงานตามแผนปฏิบัติการ
ของการยางแห่งประเทศไทย มี 4 มุมมอง: ภาพรวม · แผนปฏิบัติการประจำปี · แผนแม่บท · PA/MOU
และสร้างรายงาน PDF / Excel ได้จากหน้าเว็บ

## การไหลของข้อมูล

```
Google Sheet "Data ACP69"  ──(Apps Script)──►  Supabase: ตาราง sheet_snapshots  ◄──(anon key)──  index.html บน Vercel
   เจ้าหน้าที่บันทึกข้อมูล          ส่งเมื่อกดเมนู                 1 แถว = 1 ชีต                     อ่านอย่างเดียว
```

- เจ้าหน้าที่ยังบันทึกข้อมูลใน Google Sheet เหมือนเดิม
- ข้อมูลขึ้นเว็บเมื่อกดเมนูในชีต **📁 เมนูระบบ** อย่างใดอย่างหนึ่ง:
  - **บันทึกผลการดำเนินงานย้อนหลัง...** — บันทึกย้อนหลังเสร็จแล้วส่งข้อมูลขึ้นเว็บต่อทันที
    (รวมถึงตอนรันอัตโนมัติทุกวันที่ 20 ถ้าตั้งไว้)
  - **ส่งข้อมูลขึ้นเว็บ (Supabase) เดี๋ยวนี้** — ส่งอย่างเดียว ใช้เมื่อแก้ข้อมูลแล้วอยากให้ขึ้นเว็บทันที
- ผลการส่ง (สำเร็จ/ไม่สำเร็จ, จำนวนแถว) บันทึกไว้ในชีต **ประวัติการบันทึก**
- แก้ข้อมูลในชีตแล้วยังไม่กดส่ง เว็บจะยังแสดงข้อมูลชุดเดิม

## ติดตั้งครั้งแรก (ไม่ต้องติดตั้งโปรแกรม)

1. **Supabase**: SQL Editor → วางไฟล์ [`supabase/schema.sql`](supabase/schema.sql) → Run
   (สร้างตาราง `sheet_snapshots` และตั้ง RLS ให้ anon key อ่านได้อย่างเดียว)
2. **Apps Script** (Google Sheet → ส่วนขยาย → Apps Script): แทนที่โค้ดเดิมด้วยไฟล์ `AppScript` → บันทึก
   → โหลดชีตใหม่ → เมนู **📁 เมนูระบบ > ตั้งค่า Supabase Secret Key** → วาง `service_role` key
   หรือ secret key (`sb_secret_...`) จาก Supabase → Project Settings → API Keys
3. กด **ส่งข้อมูลขึ้นเว็บ (Supabase) เดี๋ยวนี้** ครั้งแรก (Google จะขออนุญาตให้สคริปต์เชื่อมต่อภายนอก กดอนุญาต)

Secret key อยู่ใน Script Properties ของ Apps Script เท่านั้น — ห้ามใส่ในหน้าเว็บ ในชีต หรือใน repo
ส่วน Project URL และ anon key ใน `index.html` เปิดเผยได้ (ค่าคงที่ `SUPABASE_URL` / `SUPABASE_ANON_KEY`)

## การอัปเดต

- **ข้อมูลแผน/ผลการดำเนินงาน**: แก้ใน Google Sheet แล้วกดส่งข้อมูลขึ้นเว็บ ไม่ต้องแก้โค้ดหรือ deploy ใหม่
- **หน้าตา/โค้ดแดชบอร์ด**: ต้นฉบับอยู่ในไฟล์ `Note` (ไม่นำขึ้น repo) → คัดลอกทับ `index.html` แล้ว commit + push
- **เพิ่ม/เปลี่ยนชื่อชีต**: แก้ `SYNC_SHEETS` ใน Apps Script และ `SHEET_SPECS` ใน `index.html` ให้ตรงกัน
  (เพิ่มคอลัมน์ในชีตเดิมไม่ต้องแก้ฐานข้อมูล แต่ถ้าเกินจำนวนคอลัมน์ใน `SYNC_SHEETS` ต้องขยายตัวเลขนั้น)

## ปิดปีงบประมาณ (ผลสิ้นปี)

หลังบันทึกผลเดือนกันยายนครบแล้ว กดเมนู **📁 เมนูระบบ > ปิดปีงบประมาณ (บันทึกผลสิ้นปี)...**

- สรุปผลรายโครงการของปีงบประมาณล่าสุดในชีต "โครงการ" ลงชีต **ผลสิ้นปีงบประมาณ** (สร้างให้อัตโนมัติ) แล้วส่งขึ้นเว็บ
- ผลสิ้นปี: **บรรลุเป้าหมาย** (ทุกตัวชี้วัดมีผลเทียบเป้าทั้งปี = สำเร็จ) / **ไม่บรรลุเป้าหมาย** / **ยกเลิก**
- กดซ้ำได้ — ระบบถามก่อนเขียนทับผลของปีเดียวกัน ผลของปีอื่นในชีตไม่ถูกแตะ
- แดชบอร์ด: เลือกดูปีที่ปิดแล้ว รอบกันยายน (และข้อมูลปัจจุบันก่อนเริ่มปีใหม่) แสดงผลสิ้นปีแทน "อยู่ระหว่างดำเนินการ"
  และทุกรอบของปีนั้นใช้ชื่อ/หน่วยงาน/ยุทธศาสตร์/สถานะยกเลิกของปีนั้นเอง
- ควรปิดปีก่อนเริ่มใส่โครงการปีใหม่ในชีต "โครงการ" (ระบบปิดปีงบประมาณล่าสุดที่พบในชีต)

## Deploy (Vercel)

ไม่มีขั้นตอน build และไม่ต้องติดตั้งอะไร ไลบรารี (Chart.js, SheetJS, ExcelJS, html2canvas, jsPDF)
โหลดจาก cdnjs Vercel จะเสิร์ฟ `index.html` ที่ root โดยตรง และ deploy ใหม่อัตโนมัติเมื่อ push ขึ้น `main`

- Framework Preset: **Other**
- Build Command: *(เว้นว่าง)*
- Output Directory: *(เว้นว่าง หรือ `.`)*

`vercel.json` ตั้งค่า `X-Robots-Tag: noindex` ไว้เพื่อไม่ให้ search engine เก็บ index

## สถิติผู้เข้าชม

หน้าเว็บบันทึกการเข้าชมลงตาราง `page_views` ใน Supabase หลังโหลดเสร็จ (ไม่หน่วงการแสดงผล)
เก็บเฉพาะเวลา, รหัสสุ่มประจำเครื่อง, เปิดจาก LINE หรือไม่ และเป็นมือถือหรือไม่ — ไม่เก็บชื่อ อีเมล หรือ IP
เครื่องเดิมเปิดซ้ำภายใน 30 นาทีนับครั้งเดียว ลิงก์ในแจ้งเตือน LINE ต่อท้าย `?src=line` ไว้

ดูสถิติใน Supabase → Table Editor:
- `page_view_monthly` — รายเดือน: จำนวนครั้ง (views), จำนวนเครื่อง (visitors), เปิดจาก LINE, เปิดบนมือถือ
- `page_view_daily` — รายวัน

สถิติอ่านได้เฉพาะใน Supabase (anon key อ่านไม่ได้) จึงไม่แสดงบนหน้าเว็บ

## ความเร็ว

- คำขอข้อมูลจาก Supabase เริ่มตั้งแต่ต้น `<head>` ขนานกับการโหลดไลบรารีและฟอนต์ (ไม่ต้องรอให้หน้าโหลดจบก่อน)
- ข้อมูลทุกชีตมาในคำขอเดียว
- SheetJS (~300 KB) โหลดเฉพาะตอนกดปุ่ม "ส่งออก Excel"; ExcelJS / html2canvas / jsPDF โหลดตอนสร้างรายงาน

## หมายเหตุด้านข้อมูล

ข้อมูลมีตัวเลขงบประมาณ/การเบิกจ่าย/ผลการดำเนินงานรายโครงการ ตาราง `sheet_snapshots` อ่านได้โดยทุกคนที่มี anon key
(ซึ่งอยู่ในหน้าเว็บ) จึงไม่ควรส่งข้อมูลส่วนบุคคลขึ้นไป — สคริปต์ไม่ส่งชีต "ประวัติการบันทึก" (มีอีเมล)
หากต้องจำกัดผู้เข้าถึงหน้าเว็บ แนะนำให้เปิด Deployment Protection ของ Vercel (Password / Vercel Authentication)
และหลังย้ายมาใช้ Supabase แล้ว สามารถปิดการแชร์ Google Sheet แบบ "ทุกคนที่มีลิงก์" ได้
