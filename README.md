# แดชบอร์ดติดตามแผนปฏิบัติการ กยท. ปีงบประมาณ 2569

เว็บแดชบอร์ดหน้าเดียว (static HTML) สำหรับติดตามผลการดำเนินงานตามแผนปฏิบัติการ
ของการยางแห่งประเทศไทย มี 4 มุมมอง: ภาพรวม · แผนปฏิบัติการประจำปี · แผนแม่บท · PA/MOU
และสร้างรายงาน PDF / Excel ได้จากหน้าเว็บ

## แหล่งข้อมูล

`index.html` ดึงข้อมูลสดจาก Google Sheet ทุกครั้งที่เปิดหน้าเว็บ (ผ่าน gviz CSV)

- Sheet ID: `1l35SXQ3UBmN2DNC5s3jErryeoLElwHnkrhALdQT8s0c` (ค่าคงที่ `GOOGLE_SHEET_ID` ใน `index.html`)
- ชีตที่ใช้: ยุทธศาสตร์, โครงการ, ผลการดำเนินงาน, โครงการสำคัญ, ตัวชี้วัดโครงการ, ตัวชี้วัดองค์กร,
  แผนแม่บท, เชื่อมโยงโครงการ, ส่วนงานภายใต้ผู้บริหาร, ผลการดำเนินงานย้อนหลัง
  (ดู `SHEET_SPECS` / `SHEET_RANGES` ใน `index.html` สำหรับคอลัมน์ที่ต้องมี)
- ชีตต้องแชร์แบบ **"ทุกคนที่มีลิงก์ – ผู้มีสิทธิ์อ่าน"** ไม่เช่นนั้นหน้าเว็บจะแสดงข้อความโหลดข้อมูลไม่สำเร็จ
- ถ้าชีตมีหลายปีงบประมาณ (คอลัมน์ `Fiscal_Year`) แดชบอร์ดจะแสดงเฉพาะปีล่าสุด

## การอัปเดต

- **ข้อมูลแผน/ผลการดำเนินงาน**: แก้ใน Google Sheet ได้เลย ไม่ต้องแก้โค้ดหรือ deploy ใหม่
- **หน้าตา/โค้ดแดชบอร์ด**: ต้นฉบับอยู่ในไฟล์ `Note` (ไม่นำขึ้น repo) → คัดลอกทับ `index.html` แล้ว commit + push

## Deploy (Vercel)

ไม่มีขั้นตอน build และไม่ต้องติดตั้งอะไร ไลบรารี (Chart.js, PapaParse, SheetJS, ExcelJS, html2canvas, jsPDF)
โหลดจาก cdnjs Vercel จะเสิร์ฟ `index.html` ที่ root โดยตรง และ deploy ใหม่อัตโนมัติเมื่อ push ขึ้น `main`

- Framework Preset: **Other**
- Build Command: *(เว้นว่าง)*
- Output Directory: *(เว้นว่าง หรือ `.`)*

`vercel.json` ตั้งค่า `X-Robots-Tag: noindex` ไว้เพื่อไม่ให้ search engine เก็บ index

## หมายเหตุด้านข้อมูล

ข้อมูลมีตัวเลขงบประมาณ/การเบิกจ่าย/ผลการดำเนินงานรายโครงการ โปรดตรวจสอบสิทธิ์การเผยแพร่
ก่อนตั้งค่า deployment เป็นสาธารณะ แนะนำให้เปิด Deployment Protection ของ Vercel
(Password / Vercel Authentication) หากต้องจำกัดผู้เข้าถึง — แต่ Google Sheet ที่แชร์แบบมีลิงก์
ยังเปิดดูได้โดยตรงสำหรับผู้ที่ทราบ Sheet ID
