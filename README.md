# แดชบอร์ดติดตามแผนปฏิบัติการ กยท. ปีงบประมาณ 2569

เว็บแดชบอร์ดหน้าเดียว (static HTML) สำหรับติดตามผลการดำเนินงานตามแผนปฏิบัติการ
ของการยางแห่งประเทศไทย และแจ้งเตือนสถานะโครงการที่ต้องเร่งรัด

- ข้อมูลผลการดำเนินงาน ณ 31 ส.ค. 2569 (ไตรมาส 4) + ข้อมูลย้อนหลัง มิ.ย./ก.ค. 2569 สำหรับกราฟแนวโน้ม
- ข้อมูลทั้งหมดฝังอยู่ใน `index.html` (แท็ก `<script id="acp-data" type="application/json">`)

## Deploy (Vercel)

ไม่มีขั้นตอน build — เป็นไฟล์ static ล้วน Vercel จะเสิร์ฟ `index.html` ที่ root โดยตรง

- Framework Preset: **Other**
- Build Command: *(เว้นว่าง)*
- Output Directory: *(เว้นว่าง หรือ `.`)*

`vercel.json` ตั้งค่า `X-Robots-Tag: noindex` ไว้เพื่อไม่ให้ search engine เก็บ index

## การอัปเดตข้อมูลรอบถัดไป

แทนที่ JSON ในแท็ก `<script id="acp-data">` ด้วยชุดข้อมูลรอบใหม่ (โครงสร้างเดิม) แล้ว commit + push
สคริปต์สกัดข้อมูลจากไฟล์ export (PowerShell) เก็บไว้นอก repo

## หมายเหตุด้านข้อมูล

ไฟล์นี้มีตัวเลขงบประมาณ/การเบิกจ่าย/ผลการดำเนินงานรายโครงการ โปรดตรวจสอบสิทธิ์การเผยแพร่
ก่อนตั้งค่า deployment เป็นสาธารณะ แนะนำให้เปิด Deployment Protection ของ Vercel
(Password / Vercel Authentication) หากต้องจำกัดผู้เข้าถึง
